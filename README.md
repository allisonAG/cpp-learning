# Overview

This program displays "Hello World!" in the console.

The purpose of this software is to practice creating, compiling, and running a simple C++ program that prints a message to the console.

[Software Demo Video](https://youtu.be/GFbnVBoap6w)

# Development Environment

The tools used to develop this software were VS Code, MSYS2, the g++ compiler, and Git.
The programming language used was C++.
